# ウィザーズ＆ウォーリアーズ 日本語化MOD

GOG.com 版「Wizards & Warriors」を日本語で遊べるようにする、非公式のファンメイドMODです。
開発元・販売元とは関係ありません。

- サイト（紹介・入れ方）: https://higesho.github.io/wizards-warriors-ja/
- ダウンロード: [リリース](https://github.com/higesho/wizards-warriors-ja/releases/latest) の `WizardsWarriors_JP.zip`
- ウルティマ シリーズの日本語化: https://higesho.github.io/ultima-ja/
- マイト・アンド・マジック シリーズの日本語化: https://higesho.github.io/mm-ja/
- ランズ・オブ・ロア シリーズの日本語化: https://higesho.github.io/lol-ja/
- D&D シリーズの日本語化: https://higesho.github.io/dnd-ja/

## 入れ方

1. `WizardsWarriors_JP.zip` の中身を、ゲームのフォルダ（`deep6.exe` があるフォルダ）にそのまま展開します。
2. `deep6.exe` と同じ場所に `dinput.dll` と `WWJP` フォルダが増えれば完了です。
3. いつもどおり GOG Galaxy やショートカットから起動します。

外すときは、`dinput.dll` と `WWJP` フォルダを消せば英語版に戻ります。
ゲームのファイルは書き換えません。配布物には原作のプログラムやデータは入っていません。
